# 🏛️ BUILDEX.PL - B2B Architectural & Building Supplies (Demo Project)

A high-performance, fully responsive B2B Architectural & Building Supplies Web Platform designed for facade contractors, architectural studios, and commercial specifiers across Europe.

---

## 🌐 Live Demo Preview
**Live URL:** `[https://b2b-demo-project-cc7d95.netlify.app/]`

---

## 🛠️ Tech Stack
- **Frontend Core:** HTML5, CSS3 (Custom Design Tokens, CSS Variables, Flexbox, CSS Grid)
- **Scripting & Logic:** Vanilla ES6+ JavaScript (Zero external framework dependencies)
- **Typography & Icons:** Google Fonts (**Outfit** for Headings, **Inter** for Body text)

---

## 🌟 Key Features
- **🌓 Light & Dark Mode Toggle:** Persistent theme switching saved in `localStorage`.
- **🔍 Real-Time Live Navbar Search:** Instant product matching dropdown across 20 materials with thumbnail, SKU, and price preview.
- **🛍️ Hybrid Product Catalog:** Instant Grid View and Compact Mobile-Optimized List View Toggle with 8-item pagination.
- **🔬 Dynamic Product Detail Page (`?id=1..20`):** 3D Image Hover Zoom, Animated Stock Pulse Dot, Continuous Infinite Marquee Ticker, and 3D BIM Technical Download Hub.
- **🏛️ B2B Engineering Contact Desk:** Direct contact channel cards, glassmorphic inquiry form, Warsaw HQ logistics box, and interactive FAQ accordion.
- **📱 100% All-Device Responsiveness:** Fully tested from 300px smartphones up to 1440px+ ultra-wide desktop screens with zero side-scrolling or text overflow.
